# 研究设计与实现边界

研究标题：Responsibility-Aware Adaptive Assistance in Large-Area Collaborative Visual Search。

申请书提出研究“大范围协作视觉搜索中，目标责任人与实际朝向覆盖不匹配”是否造成漏检，以及责任感知的提示/临时移交是否改善两人团队表现。捕鱼是抽象搜索目标的任务载体。

## 四种条件的原型映射

| 条件 | 捕获权限 | 提示/移交 |
| --- | --- | --- |
| FixedRole | 仅原责任人；干扰项不可捕获 | 无 |
| SharedRole | A/B 均可捕获所有非干扰目标 | 无 |
| ResponsibleCue | 仅原责任人 | 可见目标的责任人覆盖缺口持续达到阈值后，生成责任人方向提示 |
| AdaptiveHandoff | 原责任人始终有权限；可移交目标允许另一人获得限时权限 | 保留责任人提示；队友覆盖目标，且责任人存在持续缺口或可见责任目标负荷较高时移交 |

所有阈值和目标生成比例都是工程默认值，待 pilot 确认。当前目标类型按 A、B、干扰、可移交 A、可移交 B 五项重复，路线按固定随机种子选择。这样可以复现，不应把顺序可预测的调试排程直接用于正式实验；正式排程应预先生成、随机化并锁定每个 block 的刺激清单，反平衡条件、鱼外观与责任映射。

原型只对标记为 transferable 的鱼移交，一条鱼最多一次，持续默认 4 秒。接收者输入失效会提前撤销权限。工作负荷代理定义为可见且在本人监视扇区内、仍由本人原始负责的活跃鱼数量；这不是认知负荷测量，也没有声称经过验证。

## 记录与指标

- 捕获率：捕获数 /（捕获数 + 自然离场遗漏数）；另报未解决/删失目标数，不能将中止数据混入完整 block。
- 反应时间：当前 `capture` 事件给出从生成算起的时间；从首次实际出现或重新出现算起的时间需结合可见性事件另算。
- 错误捕获：wrong_owner 与 wrong_distractor 分开；错误尝试不会移除目标。
- 重复操作：保留双人所有 button_press 与结果事件，可按预先约定的时间窗定义，而不在原型中任意写死统计口径。
- 责任覆盖缺口：可见目标且责任人的有效头部扇区未覆盖；使用实际采样间隔，排除无效输入和长采样缺口。
- 队友补偿覆盖：责任人未覆盖、队友覆盖同一可见目标的时段。
- 团队盲区时间：至少一个活跃可见目标未被任一人的有效扇区覆盖的时间；也应区分“任何目标未覆盖”和“全部目标未覆盖”，正式分析前锁定定义。
- 监视方向重叠与头部运动量：由独立 orientation.csv 计算，使用角度环绕差，避免 179° 到 -179° 被计为 358°。

原型的可见性指鱼中心到共同观察点的射线是否被实体礁石挡住；鱼身体部分可见与完全遮挡并未做像素级区分。捕获判定使用近似球形目标碰撞体和真实礁石 MeshCollider。它支持遮挡调试，但不构成感知可见性测量。目标大小、碰撞体与视觉外轮廓需 pilot 校准。

## 申请书中尚待完成的部分

硬件串口/无线协议、双 IMU 同步与漂移处理、独立提示通道、270° 现场标定、NASA-TLX 与干扰/信任/角色清晰度问卷、正式随机化刺激排程、被试内实验流程及混合效应统计分析。样本量按照申请书在 pilot 后确定。

四条件的建议 Williams 顺序为 1-2-4-3、2-3-1-4、3-4-2-1、4-1-3-2，按 participant pair 轮换；代码提供顺序生成函数，当前 HUD 仍由研究员手动选择条件。条件顺序与鱼类型/任务负荷的反平衡是不同问题。

这份映射提取申请书中的研究内容并补充工程定义；不会把工程假设冒充申请书原文或经验证的科学结论。
